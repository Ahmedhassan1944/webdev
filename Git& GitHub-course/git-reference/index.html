📥

git clone

Clone a remote repository to your local machine.

git clone https://github.com/user/repo.git
git clone git@github.com:user/repo.git
Basic
📊

git status

Show the status of your working directory and staging area.

git status
git status -s  # Short format
Basic
➕

git add

Add file changes to the staging area for the next commit.

git add file.txt      # Single file
git add .             # All changes
git add -p            # Interactive
Basic
💾

git commit

Save staged changes as a permanent snapshot in history.

git commit -m "message"
git commit -am "msg"  # Add + commit
Basic
↩️

git restore

Discard changes in the working directory or unstage files.

git restore file.txt      # Discard changes
git restore --staged file  # Unstage file
Branching
🌿

git branch

List, create, or delete branches in your repository.

git branch            # List branches
git branch new-feat   # Create branch
git branch -d old     # Delete branch
Branching
🔀

git checkout

Switch branches or restore working tree files.

git checkout main
git checkout -b new-feature  # Create & switch
Branching
🔗

git merge

Integrate changes from one branch into the current branch.

git checkout main
git merge feature-branch
Branching
📦

git stash

Temporarily shelve changes to switch context quickly.

git stash             # Save changes
git stash pop         # Restore changes
git stash list        # View stashes
Branching
🔄

git rebase

Reapply commits on top of another base branch.

git rebase main
git rebase -i HEAD~3   # Interactive
Remote
🌐

git remote

Manage connections to remote repositories.

git remote -v                  # List remotes
git remote add origin <url>   # Add remote
git remote remove origin       # Remove
Remote
⬆️

git push

Upload local commits to the remote repository on GitHub.

git push origin main
git push -u origin main    # Set upstream
git push --force           # Force push
Remote
⬇️

git pull

Fetch and integrate changes from a remote repository.

git pull origin main
git pull --rebase origin main
Remote
📡

git fetch

Download objects from remote without merging them.

git fetch origin
git fetch --all
History
📜

git log

View the full commit history of the repository.

git log
git log --oneline --graph
git log -n 5
History
🔍

git diff

Show differences between commits, branches, or working tree.

git diff              # Unstaged changes
git diff --staged     # Staged changes
git diff HEAD~1 HEAD  # Between commits

⏪

git reset

Move HEAD to a previous commit, optionally modifying index.

git reset --soft HEAD~1  # Keep staged
git reset --hard HEAD~1  # Discard all
History

Fundamentals

Core Concepts

The essential vocabulary every developer needs to master Git.

📁

Working Directory

The folder on your computer where you write and edit code. Files here are either untracked or modified.

📋

Staging Area

Also called the "index". A preparation zone — files you've git added live here, waiting for the next commit.

💾

Local Repository

The .git hidden folder inside your project. It holds the complete history of every commit ever made.

☁️

Remote Repository

A hosted version of your project (GitHub, GitLab, Bitbucket). Shared with collaborators worldwide.

🌿

Branch

A parallel version of your codebase. main is the default. Create branches to work on features safely.

📸

Commit

A timestamped snapshot of staged changes. Commits form a permanent, immutable chain — the project timeline.

🔗

Merge

Combine changes from one branch into another. Git auto-merges when possible; conflicts require manual resolution.

🔄

Pull Request

A GitHub feature to propose merging your branch into the main codebase. Enables team code review and discussion.

Security & Authentication

Generate & Test GitHub SSH Keys

Securely connect your local machine to GitHub without typing your password every time.

Why SSH?

Why SSH Keys are Used

  • Problem with HTTPS: Requires a personal access token (or password) every time you push or pull.
  • Benefits of SSH: Uses cryptographic keys for secure, passwordless authentication.
Key Pair

SSH Key Pair

SSH uses two linked keys:

  • Private Key (id_rsa): Stays on your machine. NEVER share this.
  • Public Key (id_rsa.pub): Uploaded safely to GitHub.
Generate Key

Generate SSH Key

Run the following command in your terminal, replacing the email with your GitHub email:

ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

Explanation:

  • ssh-keygen: The key-generation program.
  • -t rsa: Specifies the RSA algorithm.
  • -b 4096: Specifies a strong 4096-bit key size.
  • -C "email": Adds a label (comment) to identify the key.
Passphrase

Optional Passphrase

When prompted, you can enter an optional passphrase for extra security. If someone steals your laptop, they still need the passphrase to use the key.

Add to GitHub

Add Public Key to GitHub

  1. Copy the contents of ~/.ssh/id_rsa.pub
  2. Go to GitHub ➔ Settings
  3. Click SSH and GPG keys
  4. Click New SSH key and paste the contents.
Test Connection

Test Authentication

Verify that your key is correctly set up and recognized by GitHub.

ssh -T git@github.com

Expected Output:

bash — ssh-test
$ ssh -T git@github.com
Hi username! You've successfully authenticated, but GitHub does not provide shell access.
